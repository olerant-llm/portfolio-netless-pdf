# ネットレスPDF

PDFを外部に送らず、1つの編集画面で回転・並べ替え・ページ追加・削除・トリミングなどを行うWindows向けアプリです。透かし、ページ番号、文書情報、署名画像、画像・文字の取り出し、パスワード付き保存にも対応します。

PaperKnifeを基に、開いた文書へ編集を重ねる画面と日本語操作を追加した派生版です。元プロジェクト: https://github.com/potatameister/PaperKnife 。元の著作権表示とAGPL-3.0以降の利用条件を引き継ぎます。

## 起動

Node.js 22系以上とnpmを用意します。次の操作は必要な部品をインターネットから取得します。

```powershell
cd app
npm ci
npm run dev
```

表示されたローカルURLをブラウザーで開きます。Windows本体を作る場合は、Rust、Visual StudioのC++開発環境、WebView2も必要です。部品を準備した後、`app`内で次を実行します。

```powershell
npx tauri build
```

生成先は `app/src-tauri/target/release/` です。公開ソースに実行ファイルやインストーラーは含めていません。アプリ内のPDF処理は端末内で行います。

## 現在の状態

元版の記録では242件の自動確認、Windows本体の操作確認、外部通信0件を確認済みです。この公開用コピーでは動作確認を実行していません。

- AES-128で保護されたPDFの解除は対応を止めています。RC4系とAES-256が対象です。
- 実際に電子署名されたPDFの検証と、オフライン対応インストーラーの導入確認は未完了です。署名画像の貼付は電子署名ではありません。
- 白黒化・軽量化はページを画像化するため、文字検索や文書内の一部情報が失われます。処理前に画面で説明します。
- 既存の `npm run lint` はESLint設定の不足により使えません。既存依存部品の更新検討も残っています。
- 元の画面用ソースも一部残っていますが、製品の入口は `app/src/ViewerApp.tsx` です。
